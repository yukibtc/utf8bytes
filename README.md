# UTF-8 Bytes

A cheaply cloneable UTF-8 string type, built on top of [`bytes::Bytes`](https://docs.rs/bytes).

## Crate Feature Flags

The following crate feature flags are available:

| Feature                    | Default | Description                                                |
|----------------------------|:-------:|------------------------------------------------------------|
| `std`                |   Yes    | Enable the `std` library              |
| `alloc`                |   Yes    | Enable the `alloc` library              |
